# Capturas responsive

Guardar aquí las capturas con estos nombres (o actualizar la tabla en `../CALIDAD.md`):

| Archivo              | Qué mostrar                                      |
| -------------------- | ------------------------------------------------ |
| `inicio-360.png`     | Inicio con sesión, viewport ~360 px              |
| `inicio-768.png`     | Mismo, ~768 px                                   |
| `inicio-1024.png`    | Mismo, ~1024 px                                  |
| `login-360.png`      | `/login` en móvil                                |
| `zoom-200.png`       | Página con zoom 200 % sin scroll horizontal      |

Cómo sacarlas (Chrome DevTools):

1. Abrir `https://proyecto-final-desarrollo-web-three.vercel.app` e iniciar sesión.
2. Toggle device toolbar (Ctrl/Cmd+Shift+M) → anchos 360, 768, 1024.
3. Captura de pantalla → guardar en esta carpeta.
4. Zoom del navegador al 200 % y comprobar que no hay scroll horizontal; capturar.
